# Vaqrin v0.1.4 引用实现

[现行语言规范](language-spec-v0.1.5.md)定义可用语法和生命周期合同。编译器以 LLVM 官方 C++ API 降低语义，构建并测试的入口仍为 CMake、Ninja 和原有 Python 验收。

| 层次 | 实现 |
|---|---|
| Parser | 区分声明左侧的 &name、取地址、引用类型、ref 槽位模式及间接载荷模式。只有形参与函数类型的参数列表接受 in |
| Type 和函数调用 | Reference 独立驻留。可变／只读构成类型身份；兼容适配位参与函数类型契约和间接调用，重载签名按去除兼容位后的参数判重 |
| LLVM | 引用使用指针表示；动态接口引用沿用对象地址与派发表布局。Box 继续带原有释放上下文，借用过程中不改写拥有描述符 |
| Body | 区分引用句柄与其访问位置，记录来源局部及重借用路径。按活跃绑定作用域检查读写、移动及返回来源。兼容实参暂存到完整表达式清理边界 |
| 标准包 | Vec、HashMap 和 BTreeMap 的安全查询从接收者返回引用。内部已核实的桶、节点和缓冲区地址由受限 unsafe 内建关联到接收者合同。`opt.asRef` 和 `opt.asMutRef` 通过 `ref` 直接借用可空载荷 |
| 编辑器 | 编译器以独立的类型名报告借用绑定及载荷模式。语义诊断仍使用未保存缓冲区覆盖检查入口 |

词法检查器保守地区分整个所有者，不分析同一容器的元素是否互不重叠。
可变裸地址的改写、循环回边和资源所有者的替换可能使原地址失效。编译器在这些位置丢弃已记录的裸地址来源，阻止随后用过期来源建立安全引用。
引用字段、含安全引用的容器类型实参、带借用来源的间接返回、闭包引用逃逸及多来源汇合仍受限制。
裸迭代器、切片、守卫的裸地址和 FFI 沿用其原来的指针有效性合同。
