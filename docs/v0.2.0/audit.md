## 标准库迁移依赖

1. **基础**：先完成 Copyable 与泛型模式保证、原始指针契约和按投影追踪的区域模型。core、mem、alloc、原生 runtime、C ABI 需要相同所有权边界。
2. **视图与输入**：`Token.text()` 从拥有的字符串借出 `str`，`ByteToken.bytes()` 从 Vec 借出切片。需要让来源约束贯穿返回值、调用及绑定，而不只是捕获临时值。io、bufio、text、parse、fmt 在此基础上迁移。
3. **容器与迭代器**：Vec、HashMap、BTree 的部分 `get/getMut` 已带 `from self`；旧指针访问器、Deque/List/Fixed 容器及 `iterRef/iterMut` 项仍需建立失效规则。至少测试 reserve/rehash/reallocate、删除、可变迭代与部分移动，确保不会在安全 API 内暴露悬空项。
4. **资源和下游**：为锁守卫、文件和流保留来源及清理契约；然后迁移 errors、unicode、num/math、JSON/Serde、CSV/TOML、regex、URL、log 和协议包。验收实际生成的 Serde、Protobuf 和 RPC 源码，不以生成器能启动替代编译验证。
